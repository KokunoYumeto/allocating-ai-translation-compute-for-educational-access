# Tính toán toán học và thí nghiệm có thể tái lập — bản tiếng Việt

Đây là bản tiếng Việt hoàn chỉnh trong phạm vi O002/B80: hai bài nhập môn bắt
buộc, mười hai bài chính và 75 bài tập có gợi ý cùng lời giải đầy đủ. Nội dung
bao quát Python từ đầu, NumPy/SciPy, SymPy, SageMath, trực quan hóa, kiểm thử,
nguồn gốc dữ liệu, tự động hóa và ranh giới giữa bằng chứng tính toán với chứng
minh toán học.
