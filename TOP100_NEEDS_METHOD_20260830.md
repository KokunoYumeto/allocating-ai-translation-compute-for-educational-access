# Top-100 mathematics-needs assignment method (2026-08-30)

## Purpose and boundary

This register replaces 90 generic proxy placeholders with evidence-tiered provisional first-package classifications while preserving every original row identity and all eleven original columns byte-for-value. It does **not** claim that a country proxy is a language-specific learning outcome, that an indexed zero proves no local material exists, or that one curriculum suits every learner. The first ten audited choices are preserved unchanged.

## Evidence hierarchy

1. **language-specific** — an exact census-language education/attainment observation is registered. Only Maithili-, Bhojpuri-, and Avadhi-speaking populations in Nepal meet this tier among rows 11–100. The measure is not treated as a mathematics score or a causal language effect.
2. **territory proxy** — national/state assessment, literacy, tertiary-enrolment, internet, or home-language-instruction evidence is relevant to the target territory but not measured on the exact language population.
3. **structural scarcity** — the local record has exact population/profile evidence and sometimes detected-language OpenAlex/Wikimedia counts, but no target-language outcome. The class expresses a reversible portfolio architecture, not a measured deficit.

OpenAlex language detection and Wikimedia project counts are bibliographic/digital-presence proxies only. Missing or zero counts can mean absent, undetected, unindexed, or outside those platforms.

## Controlled need classes

- **foundational_recovery**: number sense, place value, operations, fractions and measurement before or alongside prealgebra.
- **arithmetic_to_algebra_bridge**: a diagnostic mastery path from arithmetic/fractions through Elementary Algebra/Algebra 1.
- **secondary_to_tertiary_bridge**: algebra/functions/trigonometry, precalculus, calculus readiness, proof and introductory linear algebra.
- **undergraduate_spine**: a coherent calculus, linear algebra, statistics/probability and discrete/proof sequence where school-level provision appears less likely to be the binding first gap.
- **advanced_reference_prestige**: terminology infrastructure, proof/discrete mathematics and a targeted advanced reference for small/minoritized communities where broad school remediation is not supported as the first claim.
- **bilingual_register_transfer**: an exact target-language scaffold with dual terminology and an explicit hand-off into the dominant onward instructional language; this is not blanket coverage credit for the bridge language.
- **unresolved_pending_exact_evidence**: edition-population scope or existing-supply ambiguity prevents a defensible content assignment. It is a research queue, not a zero-need claim.

## Source-baseline rule

OpenStax and the Open Logic Project are reusable open source baselines, not universal prescriptions. Each row names a sequence architecture; final unit selection must reuse suitable exact-language material before retranslating and must include diagnostics, complete worked feedback, open editable source, print/screen files, and one-download offline access.
