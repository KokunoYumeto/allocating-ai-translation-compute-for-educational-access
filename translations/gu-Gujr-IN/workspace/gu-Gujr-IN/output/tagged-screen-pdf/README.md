# ગુજરાતી રચનાત્મક PDF પ્રારૂપ

આ41પાનાંનો પાઠ સ્રોતને અનુસરતો રચનાત્મક PDF પ્રારૂપ છે. શીર્ષકો,સૂચિઓ,કોષ્ટકો,ચિત્રોના વિકલ્પો અને ગણિતના વર્ણનો ચકાસ્યાં છે. PDF/UA પ્રમાણન કે માનવી દ્વારા સ્ક્રીન-રીડર પરીક્ષણ થયું નથી.

કેટલાક PDF વાચકોમાં ગુજરાતી લખાણની નકલ કે વાંચનમાં ખામી રહે છે; PDF.jsમાં આ ખામી ખરેખર જોવા મળી છે. સુલભ વાંચન માટે સંપૂર્ણ HTML આવૃત્તિ વાપરો. આ PDFને સર્વત્ર સુલભ હોવાનો દાવો કરશો નહીં.

સ્રોત અને પરવાનગીની વિગતો માટે આ ફોલ્ડર સાથે મૂળ output ફોલ્ડર તથા notices.html રાખો. અલગ ઉમેરેલા ઉકેલોની HTMLસાથી આવૃત્તિ આ PDFમાં જોડેલી નથી.
