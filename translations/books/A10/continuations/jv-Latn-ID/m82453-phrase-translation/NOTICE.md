## Accessibility and reproducibility

Semantic offline HTML includes preserved anchors, native MathML, scrollable tables, explicit image descriptions and source answer controls. Each of the three language tracks has source-positioned written narration and SSML. The two Javanese tracks also include actual synthetic speech produced only with catalog-verified `jv-ID` voices and pinned by hashes in `audio/AUDIO.json`; no Indonesian or English audio was substituted. The files are not human recordings, and pronunciation, dialect suitability, and intelligibility remain provisional and uncertified.

The provisional adaptations and packet repairs were produced with **OpenAI Codex gpt-5.6-sol, Ultra**. See `provenance/MODEL.md`; original authorship and source credits remain unchanged.

Run `scripts/draft.py`, then `scripts/build.py` with Python and lxml; run `scripts/qa.py` for deterministic validation. `scripts/prepare.py` takes the pinned full canonical source path; `scripts/extract_pivot.py` takes a separately downloaded exact comparison ZIP. The source inputs and exact image bytes needed to rebuild readers are already included. Visual QA uses the parameterized Playwright script, with a local installed Playwright path and Edge; no remote server or TeX is required. Package hashes exclude the manifest and checksum self-reference as specified by those files.
