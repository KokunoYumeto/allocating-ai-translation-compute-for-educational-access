فنکشن دے بدلاوے دی اوسط شرح لبھنا

ہر سال قیمت دا بدلاوا اک بدلاوے دی شرح اے، کیوں جے ایہہ دسّدا اے کہ اِن پُٹ مقدار دے بدلاوے دے مقابلے وچ آؤٹ پُٹ مقدار کیویں بدل دی اے۔ اسیں متعلقہ جدول وچ ویکھ سکدے آں کہ پیٹرول دی قیمت ہر سال اِکّو مقدار نال نہیں بدلی، ایس لئی بدلاوے دی شرح مستقل نہیں سی۔ جے اسیں صرف شروع تے آخر دا ڈیٹا ورتیے، تاں اسیں مقرر عرصے لئی بدلاوے دی اوسط شرح لبھ رہے ہوواں گے۔ بدلاوے دی اوسط شرح لبھن لئی اسیں آؤٹ پُٹ قدر دے بدلاوے نوں اِن پُٹ قدر دے بدلاوے نال ونڈدے آں۔

Average rate of change= Change in output Change in input                                      = Δy Δx                                      = y 2 − y 1 x 2 − x 1                                      = f( x 2 )−f( x 1 ) x 2 − x 1

یونانی اکھر Δ (ڈیلٹا) کسے مقدار وچ بدلاوا دسّدا اے؛ اسیں ایس نسبت نوں «ڈیلٹا-y ونڈ ڈیلٹا-x» یا « y وچ بدلاوا، x. وچ بدلاوے نال ونڈیا ہویا» پڑھدے آں۔ کدی کدی اسیں Δf نوں Δy, دی بجائے لکھدے آں؛ ایہہ ہجے وی اِن پُٹ قدر دے بدلن نال فنکشن دی آؤٹ پُٹ قدر وچ آون والا بدلاوا ای وکھاندا اے۔ ایس دا مطلب ایہہ نہیں کہ اسیں فنکشن نوں بدل کے کوئی ہور فنکشن بنا رہے آں۔

بدلاوے دی شرح

بدلاوے دی شرح دسّدی اے کہ اِن پُٹ مقدار دے بدلاوے دے مقابلے وچ آؤٹ پُٹ مقدار کیویں بدل دی اے۔ بدلاوے دی شرح دیاں اکائیاں «فی اِن پُٹ اکائی، آؤٹ پُٹ اکائیاں» ہوندیاں نیں۔

دو اِن پُٹ قدراں وچکار بدلاوے دی اوسط شرح، فنکشن دیاں قدراں (آؤٹ پُٹ قدراں) دے کُل بدلاوے نوں اِن پُٹ قدراں دے بدلاوے نال ونڈ کے ملدی اے۔

Δy Δx = f( x 2 )−f( x 1 ) x 2 − x 1

کرن دا طریقہ
