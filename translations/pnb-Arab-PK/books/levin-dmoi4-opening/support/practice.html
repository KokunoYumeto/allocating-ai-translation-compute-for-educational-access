1. سیٹ تے رکناں دی گِنتی

دونوں سیٹ ویکھو۔ سانجھے رکن کیہڑے نیں؟ دونوں دے سارے رکن اکٹھے کر کے، کسے نوں دو واری گِنے بغیر، کیہڑا سیٹ بندا اے؟

A = {0, 2, 4}; B = {2, 3, 4}

A ∩ B = {2, 4}; A ∪ B = {0, 2, 3, 4}; |A ∪ B| = 4

2. فنکشن: ہر اِن پُٹ دا اک آؤٹ پُٹ

پہلے جوڑاں نوں، اِن پُٹ 0، 1 تے 2 دے سیٹ توں آؤٹ پُٹ 0، 1 تے 4 دے سیٹ ول، فنکشن کیوں آکھ سکدے آں؟ جے ہور جوڑا (1, 4) وی شامل کر دیئیے، تاں کیہہ بدلدا اے؟

{(0, 0), (1, 1), (2, 4)}

ساڈا وکھرا لکھیا حل ویکھو

پہلے ہر اِن پُٹ نوں ٹھیک اک آؤٹ پُٹ ملدا اے۔ نواں جوڑا شامل کرن نال اِن پُٹ 1 نوں دو وکھرے آؤٹ پُٹ، 1 تے 4، ملن لگ پیندے نیں۔ ہن ایہہ اوہناں دِتّے سیٹاں وچکار فنکشن نہیں۔

1 ↦ 1; 1 ↦ 4

3. ترتیب وار سلسلہ تے شروعاتی عدد

4. گراف دے راس تے کنارے

تِن راس A، B تے C نیں۔ صرف A تے B وچکار، تے B تے C وچکار کنارہ اے۔ ہر راس نال کِنّے کنارے لگدے نیں؟ کیہہ A تے C دے وچکار وی سِدھا کنارہ اے؟

V = {A, B, C}; E = {{A, B}, {B, C}}

متعلقہ سبق دوبارہ پڑھو

ساڈا وکھرا لکھیا حل ویکھو

A نال اک، B نال دو تے C نال اک کنارہ لگدا اے۔ A توں C تک B راہیں جا سکدے آں، پر A تے C وچکار سِدھا کنارہ دِتّا نہیں گیا۔ راستہ تے اک کنارہ اکو گل نہیں۔

deg(A) = 1; deg(B) = 2; deg(C) = 1; {A, C} ∉ E

5. یا، تے، تے نفی

P سچ اے تے Q جھوٹ اے۔ تِن دِتّے فقرے سچ نیں یا جھوٹ؟ ایتھے «یا» دا مطلب اے کہ گھٹ توں گھٹ اک بیان سچ ہووے؛ دونوں دا سچ ہونا وی جائز اے۔

P ∧ Q; P ∨ Q; ¬P

متعلقہ سبق دوبارہ پڑھو

ساڈا وکھرا لکھیا حل ویکھو

P تے Q دونوں سچ نہیں، ایس لئی پہلا فقرا جھوٹ اے۔ گھٹ توں گھٹ P سچ اے، سو دُوجا سچ اے۔ P دی نفی، جدوں P سچ اے، جھوٹ اے۔ ہِیٹھاں T سچ تے F جھوٹ دا نشان اے۔

P ∧ Q: F; P ∨ Q: T; ¬P: F

6. ہر دے مقابلے وچ کوئی

D = {0, 1, 2}; P(x) ⇔ 2 ∣ x
