ముందుగా ఎక్కడ మొదలుపెట్టాలి? · Placement bridge

ఇది 3–10 తరగతుల అభ్యాసకుల కోసం రూపొందిస్తున్న పునాది అభ్యాస సేతువులో మొదటి చిన్న భాగం. ఇది తరగతిని నిర్ణయించే ప్రమాణీకృత పరీక్ష కాదు. ప్రతి ప్రశ్నను చదివి, జవాబుతో పాటు కారణం రాయండి. చదవడంలో సహాయం కావాలంటే ఉపాధ్యాయుడు ప్రశ్నను చదివి వినిపించవచ్చు; గణిత జవాబును చెప్పకూడదు. సమయ పరిమితి లేదు. కాలిక్యులేటర్ అవసరం లేదు.

Original bridge additions, not OpenStax assessment items. Ask for an answer and a reason. Reading support is allowed. This is a skill-routing aid, not a validated grade-placement test. No learner data is collected.

పదాలు స్పష్టంగా · A convention that matters

ఈ పాఠంలో సహజ సంఖ్యలు (counting / natural numbers) 1 నుంచి మొదలవుతాయి. పూర్ణాంకాలు (whole numbers) 0 నుంచి మొదలవుతాయి. పూర్ణ సంఖ్యలు (integers) అంటే …, −2, −1, 0, 1, 2, … వంటి సంఖ్యలు; వాటిని తరువాత నేర్చుకుంటాం. కొన్ని ఇతర పుస్తకాలు natural numbers లో 0 ను కూడా చేరుస్తాయి. ఇక్కడ మాత్రం మూలపాఠం నిర్వచనాన్నే అనుసరిస్తాం.

ప్రారంభ ప్రశ్నలు · Entry check

  1. D01 · K1 ఖాళీ పెట్టెలో ఎన్ని బంతులు ఉన్నాయి? ఆ సంఖ్య సహజ సంఖ్యా, పూర్ణాంకమా? An empty box contains how many balls? Classify that number.
  2. D02 · K1 4 సహజ సంఖ్యా, పూర్ణాంకమా, లేక రెండూనా? కారణం చెప్పండి. Is 4 a counting number, a whole number, or both?
  3. D03 · K2 1/4, 3, 5.2, 15 లో పూర్ణాంకాలను ఎంచుకోండి. మిగిలినవి ఎందుకు కావో చెప్పండి. Select the whole numbers and explain the exclusions.
  4. D04 · K2 “6/3 ను భిన్నం రూపంలో రాశారు కాబట్టి అది పూర్ణాంకం కాదు” అని రవి అన్నాడు. ఇది సరైనదా? Does fractional notation alone mean that 6/3 is not a whole number?
  5. D05 · K3 సంఖ్యారేఖపై 2, 5 లో కుడివైపు ఏది ఉంటుంది? 2 __ 5 లో < లేదా > రాయండి. Which lies farther right? Choose the comparison sign.
  6. D06 · K3 0 నుంచి కుడివైపు ఒక్కొక్క ప్రమాణం చొప్పున మూడు అడుగులు వెళ్తే ఏ బిందువుకు చేరతాం? దాని నిరూపకం ఏమిటి? Move three unit steps right from 0; name the coordinate.
  7. D07 · K4 305 లో 3, 0, 5 అంకెల స్థాన విలువలు రాయండి. 305 = __ + __ + __ పూర్తి చేయండి. Write each digit's place value and expand 305.
  8. D08 · K4 537, 735 లో పెద్ద సంఖ్య ఏది? రెండింటిలో అంకెలు ఒకటే అయినా విలువలు ఎందుకు వేరుగా ఉన్నాయి? Compare 537 and 735 using place value.

జవాబుల ఆధారంగా దారి · Skill-based routing

ప్రతి నైపుణ్యానికి రెండు ప్రశ్నలు ఉన్నాయి: K1 = D01–D02; K2 = D03–D04; K3 = D05–D06; K4 = D07–D08. జవాబు, కారణం రెండూ సరైనప్పుడు మాత్రమే ఆ ప్రశ్నకు 1 ఇవ్వండి. సరైన జవాబు ఉన్నా కారణం లేకపోతే “కారణం అడగాలి” అని గుర్తించి ప్రస్తుతం 0 ఇవ్వండి. ఊహించిన తప్పును విద్యార్థి చేసిన తప్పుగా భావించకండి; ముందుగా వివరణ అడగండి.

ఒక నైపుణ్యంలో 2/2 వస్తే దాని సమాన స్థాయి మళ్లీ-తనిఖీ ప్రశ్నలు చేయండి. 0/2 లేదా 1/2 వస్తే కింద ఉన్న ఆ నైపుణ్యపు సహాయం చదివి, తరువాత మళ్లీ తనిఖీ చేయండి. మొత్తం మార్కుల ఆధారంగా ఒక్క నైపుణ్యంలోని లోటును దాచకండి. R01–R08 లో సంబంధిత రెండు ప్రశ్నలూ కారణాలతో సరిగా చేసినప్పుడు మాత్రమే ఆ నైపుణ్యాన్ని ఈ చిన్న యూనిట్‌కు సరిపడినట్లు గుర్తించండి. అన్ని నాలుగు నైపుణ్యాలు సిద్ధమైతే తదుపరి భాగం “స్థాన విలువతో సంఖ్యలను నమూనాలుగా చూపడం”కు వెళ్లండి. లేదంటే అవసరమైన సహాయాన్ని మళ్లీ తీసుకోండి.

మళ్లీ-తనిఖీలో K1 = R01–R02; K2 = R03–R04; K3 = R05–R06; K4 = R07–R08.

తప్పు ఎక్కడ వచ్చిందో చూద్దాం · Explain and repair

K1 · సున్నా కూడా ఒక సంఖ్య
“ఏమీ లేవు కాబట్టి సంఖ్య లేదు” అనడం పొరపాటు. వస్తువులు లేని పరిమాణాన్ని 0 సూచిస్తుంది. 1, 2, 3, … సహజ సంఖ్యలు. వీటితో 0 ను చేర్చితే 0, 1, 2, 3, … పూర్ణాంకాలు. కాబట్టి ప్రతి సహజ సంఖ్య పూర్ణాంకం కూడా; కానీ 0 సహజ సంఖ్య కాదు.
K2 · రూపం కాదు, విలువను చూడాలి
1/4 అనేది 0, 1 మధ్య ఉంటుంది; 5.2 అనేది 5, 6 మధ్య ఉంటుంది. అందువల్ల ఇవి పూర్ణాంకాలు కావు. అయితే 6/3 = 2. భిన్న రూపంలో ఉన్నా దాని విలువ పూర్ణాంకం కావచ్చు. అలాగే 4.0 = 4. కేవలం గీత లేదా దశాంశ బిందువు ఉందని నిర్ణయించకండి.
K3 · దిశ, దూరం, గుర్తు
ఈ పాఠంలో సంఖ్యారేఖపై వరుస పూర్ణాంకాలను ఒక ప్రమాణం దూరంలో గుర్తిస్తాం. కుడికి వెళ్తే సంఖ్య పెరుగుతుంది. 2 నుంచి మూడు ప్రమాణాలు కుడికి వెళ్తే 5. కాబట్టి 2 < 5. పోలిక చిహ్నంలోని విస్తరించిన వైపు పెద్ద సంఖ్యవైపు ఉంటుంది. 0 అనే బిందువునే మూలబిందువు అంటాం.
K4 · స్థాన విలువ — తదుపరి పాఠానికి వంతెన
కుడి నుంచి స్థానాలు: ఒకట్లు (ones), పదులు (tens), వందలు (hundreds). 10 ఒకట్లు = 1 పది; 10 పదులు = 1 వంద. 305 లో 3 వందలు = 300; 0 పదులు = 0; 5 ఒకట్లు = 5. మధ్యలోని 0 ను తొలగిస్తే 35 వస్తుంది; అది 305 కాదు. ఒకే సంఖ్యలో అంకెలు ఉన్న రెండు సంఖ్యలను పోల్చేటప్పుడు ఎడమ నుంచి మొదట భిన్నంగా ఉన్న స్థానాన్ని చూడండి. ఇవి మూలపాఠంలోని తదుపరి భాగానికి పరిచయంగా ఇక్కడ చేర్చిన వివరణలు.
ప్రారంభ ప్రశ్నల పూర్తి సాధనలు · Worked entry solutions
  1. D01: బంతులు లేవు, కాబట్టి సంఖ్య 0. సహజ సంఖ్యల జాబితా 1 వద్ద మొదలవుతుంది, కనుక 0 అందులో లేదు. పూర్ణాంకాల జాబితా 0 వద్ద మొదలవుతుంది, కనుక 0 పూర్ణాంకం.
  2. D02: 1, 2, 3, 4 అంటూ లెక్కించగలం, కాబట్టి 4 సహజ సంఖ్య. పూర్ణాంకాల్లో సహజ సంఖ్యలన్నీ ఉంటాయి. అందువల్ల 4 రెండూ అవుతుంది.
  3. D03: 3, 15 పూర్ణాంకాలు. 0 < 1/4 < 1; 5 < 5.2 < 6. 1/4, 5.2 పూర్ణాంకాల గుర్తుల మధ్య ఉన్నాయి, వాటి వద్ద లేవు. కాబట్టి వాటిని ఎంచుకోము.
  4. D04: రవి మాట సరైంది కాదు. 6 ను 3 సమాన భాగాలుగా పంచితే ఒక్కో భాగం 2; అంటే 6/3 = 2. 2 సహజ సంఖ్య కూడా, పూర్ణాంకం కూడా. సంఖ్య విలువను చూడాలి, రాసిన రూపాన్ని మాత్రమే కాదు.
  5. D05: 2 నుంచి 3, 4, 5 వరకు కుడికి వెళ్తాం. 5 కుడివైపు ఉంది, అందువల్ల 5 పెద్దది. సరైన పోలిక 2 < 5; విస్తరించిన వైపు 5 వైపు ఉంది.
  6. D06: మొదటి అడుగు 1 వద్దకు, రెండోది 2 వద్దకు, మూడోది 3 వద్దకు. చేరిన బిందువు నిరూపకం 3. మొదట నిల్చున్న 0 ను ఒక అడుగుగా లెక్కించకూడదు.
  7. D07: 3 వందల స్థానంలో ఉంది: 3 × 100 = 300. 0 పదుల స్థానంలో ఉంది: 0 × 10 = 0. 5 ఒకట్ల స్థానంలో ఉంది: 5 × 1 = 5. కాబట్టి 305 = 300 + 0 + 5.
  8. D08: రెండూ మూడు అంకెల సంఖ్యలు. వందల స్థానంలో 537 కు 5, 735 కు 7 ఉన్నాయి. 7 వందలు 5 వందల కంటే ఎక్కువ, కాబట్టి 735 > 537. 537 = 500 + 30 + 7; 735 = 700 + 30 + 5. అంకెల స్థానాలు మారితే వాటి స్థాన విలువలు మారుతాయి.

మళ్లీ-తనిఖీ పూర్తి సాధనలు · Worked recheck solutions
  1. R01: పక్షులు ఏవీ మిగలలేదు, కాబట్టి 0. ఈ పాఠం నిర్వచనం ప్రకారం 0 పూర్ణాంకం; సహజ సంఖ్య కాదు.
