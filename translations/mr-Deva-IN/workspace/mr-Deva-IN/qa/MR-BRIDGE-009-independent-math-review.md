## Source discrepancies sent to the drafting worker

1. EN Try It 2(a), solution paragraph `fs-id1167836798080`, prints range `{−3,−2,−1,0,2,2,3}`. Its own pair set and the ID solution require `{−3,−2,−1,0,1,2,3}`. Merely deduplicating the erroneous list would still omit 1.
2. Both source languages call Try It 1's requested range the range of a “function,” although part (b) is not a function. The broader word “relation” is required, with the source wording disclosed.
3. Figure 009's canonical EN pixels and ID pixels show `123-567-4839` and `753-469-9731`. EN alt wrongly transposes the first as `123-567-4389`; EN supplied answer wrongly prints the second as `743-469-9731`. The original source files remain unchanged.
4. Figure 008's EN/ID pixels say `Love It or List It`; EN alt/answer use lowercase `it`. This is a disclosed label-capitalization normalization, not a changed mapping.
5. Both source languages overgeneralize the two-y reasoning after the `x+y²=3` example (`fs-id1167836539656`) to every x. In fact x=3 permits only y=0, and x>3 has no real y. The one valid same-input/two-output counterexample suffices to disprove the function claim. The source paragraph ID must remain while the correction is made explicit.

The drafting worker independently confirmed these findings. The actual stable Marathi draft contains visible correction notes for all five and retains the affected source question/answer IDs. Its note also correctly distinguishes the evaluated outcomes y=1/y=5 from claims that the full original functions are constant.
