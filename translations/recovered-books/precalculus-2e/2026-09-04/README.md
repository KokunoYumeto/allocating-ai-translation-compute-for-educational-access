# Precalculus 2e — recovered Punjabi and Vietnamese sections

This is a bounded, editable teaching package, not a complete translation of the book. It continues the [preserved multilingual intake](https://github.com/KokunoYumeto/allocating-ai-translation-compute-for-educational-access/tree/ed6f2e2020118723c2a12fe3377d2273c3d8ec50/translations) without replacing its historical files.

## Read

Download and extract `precalculus-2e-recovered-20260904.zip`, then open its `index.html`. The HTML readers use local assets and semantic mathematical markup. Locale-specific README and coverage files identify the exact section and exercise coverage, source identities, exclusions and next source anchor. The package includes editable translation sources and reproducible builders, not only rendered pages.

- **Punjabi (Pakistan), native Shahmukhi:** Introduction; Functions and Function Notation; Domain and Range; Rates of Change and Behavior of Graphs (m49299, m49301, m49304, m49306). Urdu and English help are distinct from the Punjabi teaching text. An explicitly labeled original schematic replaces an excluded third-party introductory illustration; it is not a reconstruction of the original historical graph.
- **Vietnamese:** Functions and Function Notation (m49301), Domain and Range (m49304), and the preserved smaller reading sequence. The recovered later exercises and glossary are integrated into the Domain and Range section. Exercises, supplied source solutions and independently added learning support are identified separately.

These sections support the recovered secondary-to-undergraduate Punjabi bridge and the Vietnamese self-study/prerequisite pathway. Wider algebra, calculus, discrete mathematics and linear algebra work is not counted as translated here. The completed Indonesian edition is a separate, unchanged publication.

## Reproducibility and limits

`MANIFEST.json` and `SHA256SUMS.txt` identify every packaged file by path, size and SHA-256. Rebuild and validation instructions are in each locale package. Visual checks are targeted, sequential samples, not a claim of visually inspecting every possible browser or printed page. HTML is the primary reader; no newly typeset complete-book PDF is claimed.

Future work continues at the next source anchors recorded in the locale coverage files. This release completes the assigned recovered-section package, not either full language programme.
