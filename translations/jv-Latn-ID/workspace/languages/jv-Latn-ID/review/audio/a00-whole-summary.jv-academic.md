## m81243--outer-title

Pambuka Wilangan Cacah

## m81243--para-00001--objectives

Sawise ngrampungake bagean iki, sampeyan bakal bisa:
Ngenali wilangan asli lan wilangan cacah.
Nggambarake wilangan cacah nganggo model.
Ngenali nilai panggonan sawijining digit.
Nggunakake nilai panggonan kanggo nyebut wilangan cacah.
Nggunakake nilai panggonan kanggo nulis wilangan cacah.
Mbunderake wilangan cacah.

## m81243--fs-id2296006--title

Konsep Pokok

## m81243--eip-id1170196618448

Bagan “Nilai Panggonan” ngemot limalas kolom lan patang baris, kalebu irah-irahan. Ana limang klompok, saben klompok ngemot telung kolom. Klompok saka kiwa menyang tengen yaiku Trilyun, Milyar, Yuta, Éwuan, Satuan. Label kolom lan isi sel digit, saka kiwa menyang tengen:
Kolom siji, label “Atusan trilyun”: kosong.
Kolom loro, label “Sepuluh trilyun”: kosong.
Kolom telu, label “trilyun”: kosong.
Kolom papat, label “Atusan milyar”: kosong.
Kolom lima, label “Sepuluh milyar”: kosong.
Kolom enem, label “milyar”: kosong.
Kolom pitu, label “Satus yuta”: kosong.
Kolom wolu, label “Sepuluh yuta”: kosong.
Kolom sanga, label “yutanan”: lima.
Kolom sepuluh, label “Satus éwu”: loro.
Kolom sewelas, label “Sepuluh éwu”: pitu.
Kolom rolas, label “éwuan”: wolu.
Kolom telulas, label “atusan”: siji.
Kolom patbelas, label “puluhan”: sanga.
Kolom limalas, label “satuan”: papat.
Wolung sel digit sing wiwitan kosong, dudu digit nol. Wiwit kolom sanga, digit sing ditulis yaiku lima, loro, pitu, wolu, siji, sanga, papat. Wilangan ing bagan yaiku limang yuta rong atus pitung puluh wolu éwu satus sangang puluh papat.

## m81243--eip-id1170195386307--procedure

Sebutna wilangan cacah nganggo tembung.
Langkah siji. Wiwit digit paling kiwa, sebutna wilangan ing saben periode, banjur sebutna jeneng periodene. Jeneng periode satuan ora perlu disebut.

Langkah loro. Gunakna tandha koma ing panulisan wilangan kanggo misahake saben periode.

## m81243--eip-id1170195386319--procedure

Gunakna nilai panggonan kanggo nulis wilangan cacah.
Langkah siji. Kenalina tembung-tembung sing nuduhake periode. (Elinga yen periode satuan ora tau disebut.)

Langkah loro. Gawea telung panggonan kosong kanggo nuduhake cacah panggonan digit sing dibutuhake ing saben periode.

Langkah telu. Sebutna wilangan ing saben periode, banjur selehna digit-digit kasebut ing posisi nilai panggonan sing bener.

## m81243--eip-id1170195386333--procedure

Mbunderake wilangan cacah menyang nilai panggonan tartamtu.
Langkah siji. Golekana nilai panggonan sing ditemtokake. Kabeh digit ing sisih kiwa nilai panggonan kasebut tetep, kajaba yen digit ing nilai panggonan kasebut sanga; ing kahanan iki, digit ing sisih kiwane bisa owah. (Delengen Langkah telu.)

Langkah loro. Wenehana garis ing sangisore digit sing pas ing sisih tengen nilai panggonan sing ditemtokake.

Langkah telu. Temtokna apa digit iki luwih gedhé tinimbang utawa padha karo lima. Yen iya, tambahna siji ing digit ing nilai panggonan sing ditemtokake. Yen digit kasebut sanga, gantinen nganggo nol lan tambahna siji ing digit sing pas ing sisih kiwane. Yen digit kasebut uga sanga, balenana langkah iki. Yen ora, aja ngowahi digit ing nilai panggonan sing ditemtokake.

Langkah papat. Ganti kabeh digit ing sisih tengen nilai panggonan sing ditemtokake nganggo nol.

## m81243--fs-id2642858

koordinat.
Wilangan sing dipasangake karo sawijining titik ing garis wilangan diarani koordinat titik kasebut.

## m81243--fs-id2935860

wilangan asli.
Wilangan asli yaiku wilangan siji, loro, telu, lan sateruse.

## m81243--fs-id2711214

garis wilangan.
Garis wilangan digunakake kanggo nggambarake wilangan. Wilangan ing garis wilangan saya gedhé saka kiwa menyang tengen lan saya cilik saka tengen menyang kiwa.

## m81243--fs-id3330600

titik asal.
Titik asal yaiku titik kanthi label nol ing garis wilangan.

## m81243--fs-id1336470

sistem nilai panggonan.
Sistem wilangan kita diarani sistem nilai panggonan amarga nilai sawijining digit gumantung marang posisi, utawa panggonan, digit kasebut ing sawijining wilangan.

## m81243--fs-id2263270

pambunderan.
Proses nemtokake nilai watara sawijining wilangan diarani pambunderan.

## m81243--fs-id4338000

wilangan cacah.
Wilangan cacah yaiku wilangan nol, siji, loro, telu, lan sateruse.
