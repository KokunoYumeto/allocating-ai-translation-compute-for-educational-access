## fs-id1170654968998

Dalam beberapa contoh terakhir, kita menyederhanakan ekspresi dengan menggunakan urutan operasi hitung. Menentukan nilai ekspresi berarti mencari nilai ekspresi ketika variabelnya diganti dengan bilangan tertentu.
