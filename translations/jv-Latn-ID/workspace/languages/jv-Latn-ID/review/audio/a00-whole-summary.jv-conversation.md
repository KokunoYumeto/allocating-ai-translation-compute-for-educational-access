## m81243--outer-title

Miwiti Sinau Wilangan Cacah

## m81243--para-00001--objectives

Sawise sinau bagean iki, kowe bakal bisa:
Ngenali wilangan asli lan wilangan cacah.
Nggambarake wilangan cacah nganggo model.
Ngenali nilai panggonane sawijining digit.
Nganggo nilai panggonan kanggo nyebut wilangan cacah.
Nganggo nilai panggonan kanggo nulis wilangan cacah.
Mbunderake wilangan cacah.

## m81243--fs-id2296006--title

Bab-bab Sing Pokok

## m81243--eip-id1170196618448

Bagan “Nilai Panggonan” ana limalas kolom lan patang baris, kalebu judhule. Ana limang klompok, saben klompok telung kolom. Saka kiwa menyang tengen, klompoke yaiku Trilyun, Milyar, Yuta, Éwuan, Satuan. Iki label kolom lan isi sel digite, saka kiwa menyang tengen:
Kolom siji, “Atusan trilyun”, kosong.
Kolom loro, “Sepuluh trilyun”, kosong.
Kolom telu, “trilyun”, kosong.
Kolom papat, “Atusan milyar”, kosong.
Kolom lima, “Sepuluh milyar”, kosong.
Kolom enem, “milyar”, kosong.
Kolom pitu, “Satus yuta”, kosong.
Kolom wolu, “Sepuluh yuta”, kosong.
Kolom sanga, “yutanan”, lima.
Kolom sepuluh, “Satus éwu”, loro.
Kolom sewelas, “Sepuluh éwu”, pitu.
Kolom rolas, “éwuan”, wolu.
Kolom telulas, “atusan”, siji.
Kolom patbelas, “puluhan”, sanga.
Kolom limalas, “satuan”, papat.
Wolung sel digit wiwitan kosong, dudu digit nol. Wiwit kolom sanga, digite lima, loro, pitu, wolu, siji, sanga, papat. Wilangan ing bagan iki limang yuta rong atus pitung puluh wolu éwu satus sangang puluh papat.

## m81243--eip-id1170195386307--procedure

Sebutna wilangan cacahe nganggo tembung.
Langkah siji. Wiwiti saka digit paling kiwa. Sebutna wilangan ing saben periode, banjur jeneng periodene. Jeneng periode satuan aja disebut.

Langkah loro. Nganggoa tandha koma nalika nulis wilangan kanggo misahake saben periode.

## m81243--eip-id1170195386319--procedure

Nganggoa nilai panggonan kanggo nulis wilangan cacah.
Langkah siji. Golekana tembung-tembung sing nuduhake periode. (Elinga, periode satuan ora tau disebut.)

Langkah loro. Gawea telung panggonan kosong supaya katon pira panggonan digit sing dibutuhake ing saben periode.

Langkah telu. Sebutna wilangan ing saben periode, banjur selehna digit-digite ing posisi nilai panggonan sing bener.

## m81243--eip-id1170195386333--procedure

Ayo mbunderake wilangan cacah menyang nilai panggonan tartamtu.
Langkah siji. Golekana nilai panggonan sing ditemtokake. Kabeh digit ing sisih kiwane tetep, kajaba yen digit ing nilai panggonan kuwi sanga; yen mangkono, digit ing sisih kiwane bisa owah. (Delengen Langkah telu.)

Langkah loro. Wenehi garis ing ngisore digit sing pas ing sisih tengen nilai panggonan kuwi.

Langkah telu. Delengen apa digit iki luwih gedhé tinimbang utawa padha karo lima. Yen iya, tambahna siji ing digit ing nilai panggonan sing ditemtokake. Yen digit kuwi sanga, ganti nganggo nol lan tambahna siji ing digit sing pas ing sisih kiwane. Yen digit kuwi uga sanga, baleni langkah iki. Yen ora, aja ngowahi digit ing nilai panggonan sing ditemtokake.

Langkah papat. Kabeh digit ing sisih tengen nilai panggonan kuwi diganti nganggo nol.

## m81243--fs-id2642858

koordinat.
Wilangan sing dipasangake karo sawijining titik ing garis wilangan diarani koordinat titik kuwi.

## m81243--fs-id2935860

wilangan asli.
Wilangan asli yaiku wilangan siji, loro, telu, lan sateruse.

## m81243--fs-id2711214

garis wilangan.
Garis wilangan dienggo nggambarake wilangan. Wilangane saya gedhé saka kiwa menyang tengen, lan saya cilik saka tengen menyang kiwa.

## m81243--fs-id3330600

titik wiwitan.
Titik wiwitan yaiku titik sing diwenehi label nol ing garis wilangan.

## m81243--fs-id1336470

sistem nilai panggonan.
Sistem wilangan kita diarani sistem nilai panggonan amarga nilaine sawijining digit gumantung marang posisi, utawa panggonane, digit kuwi ing sawijining wilangan.

## m81243--fs-id2263270

pambunderan.
Nemokake nilai watara sawijining wilangan diarani pambunderan.

## m81243--fs-id4338000

wilangan cacah.
Wilangan cacah yaiku wilangan nol, siji, loro, telu, lan sateruse.
