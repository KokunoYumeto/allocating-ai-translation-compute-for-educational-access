Ayo mbunderake wilangan cacah menyang nilai panggonan tartamtu.

  1. Goleki nilai panggonan sing wis ditemtokake. Kabeh digit ing sisih kiwane tetep, kajaba yen digit ing nilai panggonan kuwi 9; yen mangkono, digit ing sisih kiwa bisa owah. (Delengen Langkah 3.)
  2. Wenehi garis ing ngisore digit sing pas ing sisih tengen nilai panggonan kuwi.
  3. Delengen apa digit iki luwih gedhé tinimbang utawa padha karo 5.
    • Ya—tambahna 1 ing digit ing nilai panggonan kuwi. Yen digite 9, ganti nganggo 0 lan tambahna 1 ing digit sing pas ing sisih kiwane. Yen digit kuwi uga 9, baleni langkah iki.
    • Ora—digit ing nilai panggonan kuwi aja diowahi.
  4. Kabeh digit ing sisih tengen nilai panggonan kuwi diganti nganggo nol.
Basa Jawa akademik · rancangan

Mbunderake wilangan cacah menyang nilai panggonan tartamtu.

  1. Golekana nilai panggonan sing ditemtokake. Kabeh digit ing sisih kiwa nilai panggonan kasebut ora owah, kajaba yen digit ing nilai panggonan kasebut yaiku 9; ing kahanan iku digit ing sisih kiwa bisa owah. (Delengen Langkah 3.)
  2. Wenehana garis ing sangisore digit sing pas ing sisih tengen nilai panggonan sing ditemtokake.
  3. Temtokake apa digit iki luwih gedhé tinimbang utawa padha karo 5.
    • Ya—tambahake 1 ing digit ing nilai panggonan sing ditemtokake. Yen digit kasebut 9, ganti nganggo 0 lan tambahake 1 ing digit sing pas ing sisih kiwane. Yen digit iku uga 9, baleni langkah iki.
    • Ora—aja ngowahi digit ing nilai panggonan sing ditemtokake.
  4. Ganti kabeh digit ing sisih tengen nilai panggonan sing ditemtokake nganggo nol.
Bahasa Indonesia · teks sumber

Membulatkan bilangan cacah ke nilai tempat tertentu.

  1. Temukan nilai tempat yang ditentukan. Semua digit di sebelah kiri nilai tempat itu tidak berubah, kecuali jika digit pada nilai tempat tersebut adalah 9; dalam hal itu digitnya mungkin berubah. (Lihat Langkah 3.)
  2. Garisbawahi digit di sebelah kanan nilai tempat yang ditentukan.
  3. Tentukan apakah digit ini lebih besar daripada atau sama dengan 5.
    • Ya—tambahkan 1 pada digit di nilai tempat yang ditentukan. Jika digit itu 9, gantilah dengan 0 dan tambahkan 1 pada digit tepat di sebelah kirinya. Jika digit itu juga 9, ulangi langkah ini.
    • Tidak—jangan ubah digit pada nilai tempat yang ditentukan.
  4. Ganti semua digit di sebelah kanan nilai tempat yang ditentukan dengan nol.
