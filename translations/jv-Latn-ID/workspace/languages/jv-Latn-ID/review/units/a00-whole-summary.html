Basa Jawa padinan · ngoko

Bab-bab Sing Pokok

  • Sebutna wilangan cacahe nganggo tembung.
    1. Wiwiti saka digit paling kiwa. Sebutna wilangan ing saben periode, banjur jeneng periodene. Jeneng periode satuan aja disebut.
    2. Nganggoa tandha koma nalika nulis wilangan kanggo misahake saben periode.
  • Nganggoa nilai panggonan kanggo nulis wilangan cacah.
    1. Golekana tembung-tembung sing nuduhake periode. (Elinga, periode satuan ora tau disebut.)
    2. Gawea telung panggonan kosong supaya katon pira panggonan digit sing dibutuhake ing saben periode.
    3. Sebutna wilangan ing saben periode, banjur selehna digit-digite ing posisi nilai panggonan sing bener.
  • Ayo mbunderake wilangan cacah menyang nilai panggonan tartamtu.
    1. Golekana nilai panggonan sing ditemtokake. Kabeh digit ing sisih kiwane tetep, kajaba yen digit ing nilai panggonan kuwi 9; yen mangkono, digit ing sisih kiwane bisa owah. (Delengen Langkah 3.)
    2. Wenehi garis ing ngisore digit sing pas ing sisih tengen nilai panggonan kuwi.
    3. Delengen apa digit iki luwih gedhé tinimbang utawa padha karo 5. Yen iya, tambahna 1 ing digit ing nilai panggonan sing ditemtokake. Yen digit kuwi 9, ganti nganggo 0 lan tambahna 1 ing digit sing pas ing sisih kiwane. Yen digit kuwi uga 9, baleni langkah iki. Yen ora, aja ngowahi digit ing nilai panggonan sing ditemtokake.
    4. Kabeh digit ing sisih tengen nilai panggonan kuwi diganti nganggo nol.
Basa Jawa akademik · rancangan

Konsep Pokok

  • Sebutna wilangan cacah nganggo tembung.
    1. Wiwit digit paling kiwa, sebutna wilangan ing saben periode, banjur sebutna jeneng periodene. Jeneng periode satuan ora perlu disebut.
    2. Gunakna tandha koma ing panulisan wilangan kanggo misahake saben periode.
  • Gunakna nilai panggonan kanggo nulis wilangan cacah.
    1. Kenalina tembung-tembung sing nuduhake periode. (Elinga yen periode satuan ora tau disebut.)
    2. Gawea telung panggonan kosong kanggo nuduhake cacah panggonan digit sing dibutuhake ing saben periode.
    3. Sebutna wilangan ing saben periode, banjur selehna digit-digit kasebut ing posisi nilai panggonan sing bener.
  • Mbunderake wilangan cacah menyang nilai panggonan tartamtu.
    1. Golekana nilai panggonan sing ditemtokake. Kabeh digit ing sisih kiwa nilai panggonan kasebut tetep, kajaba yen digit ing nilai panggonan kasebut 9; ing kahanan iki, digit ing sisih kiwane bisa owah. (Delengen Langkah 3.)
    2. Wenehana garis ing sangisore digit sing pas ing sisih tengen nilai panggonan sing ditemtokake.
    3. Temtokna apa digit iki luwih gedhé tinimbang utawa padha karo 5. Yen iya, tambahna 1 ing digit ing nilai panggonan sing ditemtokake. Yen digit kasebut 9, gantinen nganggo 0 lan tambahna 1 ing digit sing pas ing sisih kiwane. Yen digit kasebut uga 9, balenana langkah iki. Yen ora, aja ngowahi digit ing nilai panggonan sing ditemtokake.
    4. Ganti kabeh digit ing sisih tengen nilai panggonan sing ditemtokake nganggo nol.
Bahasa Indonesia · teks sumber

Konsep Utama

  • Sebutkan bilangan cacah dengan kata-kata.
    1. Mulai dari digit paling kiri, sebutkan bilangan pada setiap periode, lalu sebutkan nama periodenya. Jangan sebutkan nama periode satuan.
    2. Gunakan tanda koma dalam penulisan bilangan untuk memisahkan setiap periode.
  • Gunakan nilai tempat untuk menulis bilangan cacah.
    1. Identifikasi kata-kata yang menunjukkan periode. (Ingat bahwa periode satuan tidak pernah disebutkan.)
    2. Buat tiga tempat kosong untuk menunjukkan banyaknya nilai tempat yang diperlukan dalam setiap periode.
    3. Sebutkan bilangan pada setiap periode, lalu tempatkan digit-digitnya pada posisi nilai tempat yang benar.
  • Membulatkan bilangan cacah ke nilai tempat tertentu.
    1. Temukan nilai tempat yang ditentukan. Semua digit di sebelah kiri nilai tempat tersebut tidak berubah, kecuali jika digit pada nilai tempat itu adalah 9; dalam hal tersebut digitnya mungkin berubah. (Lihat Langkah 3.)
    2. Garisbawahi digit di sebelah kanan nilai tempat yang ditentukan.
    3. Tentukan apakah digit ini lebih besar daripada atau sama dengan 5. Jika ya, tambahkan 1 pada digit di nilai tempat yang ditentukan. Jika digit itu 9, gantilah dengan 0 dan tambahkan 1 pada digit tepat di sebelah kirinya. Jika digit itu juga 9, ulangi langkah ini. Jika tidak, jangan ubah digit pada nilai tempat yang ditentukan.
    4. Ganti semua digit di sebelah kanan nilai tempat yang ditentukan dengan nol.

koordinat

Suatu bilangan yang berpasangan dengan suatu titik pada suatu garis bilangan disebut koordinat titik tersebut.

Bilangan asli adalah bilangan 1, 2, 3,….

garis bilangan

Garis bilangan digunakan untuk memvisualisasikan bilangan. Bilangan-bilangan pada garis bilangan membesar dari kiri ke kanan dan mengecil dari kanan ke kiri.

titik awal

Titik awal adalah titik berlabel 0 pada garis bilangan.

sistem nilai tempat

Sistem bilangan kita disebut sistem nilai tempat karena nilai suatu digit bergantung pada posisi, atau tempat, digit tersebut dalam suatu bilangan.

pembulatan
