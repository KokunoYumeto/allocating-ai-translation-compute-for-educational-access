   names. The Indonesian pivot already adapts that English-specific morphology
   away. The Javanese translation follows that adaptation, uses the period's
   magnitude name after its count, and omits the ones label. It does not teach
   an irrelevant English suffix operation.
2. `fs-id3400199` retains the textbook convention of not inserting `lan` inside
   a whole-number name. It is not evidence that everyday Javanese universally
   prohibits the conjunction. In narration the emphasized metalinguistic `lan`
   needs an unmistakable quoted-word cue; flat “tembung lan ora…” can sound
   like an ordinary conjunction. No such narration was generated here.

   both source instructions prescribe them and the English answers supply
   them. Target-only restoration adds one missing inter-period comma at
   `fs-id1469854`, four at `fs-id1278691`, two at `fs-id1394436`, two at
   `fs-id2243722`, and one at `fs-id1269733`. This is declared in the edit
   ledger. Indonesian keys/pivot, numeric strings, and mathematical tokens
   are unchanged; ordinary translated discourse punctuation is also allowed.
4. Both source tables declare `tgroup cols="3"`, yet all five rows have exactly
   two `entry` elements and no header row. Retain this inherited structure.
   Do not silently add a third semantic column or fabricate header/blank-cell
   content. Integration needs a scoped table rule and an explicit accessibility

5. Both sources pose the phone example as an unspecified month in 2014 and
   name April in its solution. Both details are preserved; the draft does not

6. The seconds exercise corresponds arithmetically to 365×24×60×60. The source
