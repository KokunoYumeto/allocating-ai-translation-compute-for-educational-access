# Allocating AI Compute for Global Educational Access

This repository contains the version 2.0.0 paper, accessible reader, structured
evidence, reproducibility code, and deterministic QA receipts.

- [Accessible HTML reader](https://kokunoyumeto.github.io/allocating-ai-translation-compute-for-educational-access/)
- [Paper (PDF)](PAPER.pdf)
- [Editable paper (DOCX)](PAPER.docx)
- [Source manuscript (Markdown)](PAPER.md)
- [Zenodo DOI](https://doi.org/10.5281/zenodo.22288883)

The evidence freeze contains 1,077 authority targets: 204 source-authorized
direct-person targets, 2 separately comparable stage opportunities, and 871
visible unranked or contextual targets. It publishes a complete Top 100
reference order together with stage, accessibility, signed-language,
displacement, endangered/prestige-domain, and bridge/interlanguage lanes.

The direct-person order is a model-conditional planning projection under common
priors and is highly population-dominant because many exact target-specific
scarcity and academic-language-overlap measurements remain unavailable. The
paper publishes those limitations, partial-identification results, sensitivity
tests, and the unranked evidence universe rather than treating the ordered list
as directly observed fact.

Need and standardized from-scratch compute efficiency exclude local holdings,
prior project completion, sunk compute, and project convenience. Research
synthesis, quantitative analysis, drafting, and reproducibility work used
OpenAI Codex gpt-5.6-sol, Ultra. Source authors and public-project contributors
retain their original credits.
