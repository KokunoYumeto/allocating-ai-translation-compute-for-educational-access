# Ownership and whole-assignment scope

The original dispatch is a material-assignment reference. Each task owns its **entire assigned translation and workflow**, not only an initial pilot. Indonesian rank 1 is outside this coordinator's assignment. Existing task names are retained below; branch names containing "pilot" are historical and do not reduce the scope.

| Rank | Task | Product focus | Assigned materials |
|---:|---|---|---|
| 2 | Bangladesh Bangla Mathematics Translation | Grades 2–5 foundational numeracy | A00, selected A10, AX-1, AX-3 |
| 3 | Telugu Mathematics Translation | Grades 3–10 Telugu–English mastery bridge | A00–A30, then B10 reasoning |

A00 = Prealgebra; A10 = Elementary Algebra; A20 = Intermediate Algebra; A30 = Precalculus. B10 is Discrete Mathematics: An Open Introduction, with Open Logic a separate supplemental reference, not an interchangeable B10 assignment. Other program definitions and source pins are in [SOURCES.md](SOURCES.md).

The table does not invent a new cutoff for "selected" material. Recover the language's detailed source inventory and latest actual user direction before scheduling an omitted module. Adaptation, learner companions, native-language canon consultation and the assigned AX/crosswalk work remain part of the workflow.

The coordinator owns the shared index, source-warning distribution, cross-PC prerequisites and issue ownership. Language tasks own translation, ongoing canon consultation, source-faithfulness, original-answer labeling, integration and their own readiness receipts. The user or runtime capability owner handles the few app-control/access limitations listed in [ISSUES.md](ISSUES.md).
